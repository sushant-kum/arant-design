# ARANT DESIGN · Mockups

**Status: planned.** Product, packaging and in-situ mockups.

## Intended contents

| Folder         | For                                                                                    |
| -------------- | -------------------------------------------------------------------------------------- |
| `product/`     | Trays, coasters, candle holders and other objects showing the debossed or moulded mark |
| `packaging/`   | Kraft boxes, labels, hang tags, stickers, tissue and wrapping bands                    |
| `print/`       | Business cards, thank-you cards, stationery                                            |
| `digital/`     | Instagram, website and email mockups                                                   |
| `environment/` | Studio signage and retail displays                                                     |

## Guidelines

- Place the logo from [`brand/identity`](../identity/) (usually `logo/svg/` or `print/pdf/`). Never redraw or retype it.
- Keep editable source files (PSD, Figma exports, Blender scenes) next to their rendered output, in a `source/` folder.
- Commit large images through Git LFS (see the root `.gitattributes`).
- Mark example names and prices as examples.
