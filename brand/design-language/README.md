# ARANT DESIGN · Design language

**Status: planned.** How the brand looks and speaks beyond the logo.

## Intended contents

| Folder         | For                                                                                                                  |
| -------------- | -------------------------------------------------------------------------------------------------------------------- |
| `principles/`  | The few ideas every decision comes back to: architectural, tactile, understated, warm, intentional                   |
| `pattern/`     | The symbol-as-texture system (tissue paper, box liners, web backgrounds). The starting rule is in the identity guide |
| `photography/` | Light, surfaces, styling and cropping for product and process photography                                            |
| `layout/`      | Grids and spacing for print, packaging and screens                                                                   |
| `voice/`       | Tone of voice, naming (products, collections) and copy patterns                                                      |
